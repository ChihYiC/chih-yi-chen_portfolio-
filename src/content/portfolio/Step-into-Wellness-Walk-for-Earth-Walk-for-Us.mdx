# Project Overview

Step into Wellness is a wellness and step-tracking app concept designed to help users build healthier daily routines. The app encourages walking through goal setting, reminders, progress tracking, and friend interaction.

The project explores how digital products can motivate users to stay active through simple interaction flows and supportive feedback.

## Problem

Many users want to exercise more but often forget to move during busy daily routines. Some users also find reminder notifications annoying, while others need more motivation to continue using a wellness app.

The main design challenge was to create a step-tracking experience that feels useful, motivating, and easy to use without overwhelming users.

## Goal

The goal was to design a wellness app that helps users:

* Set daily step goals
* Track steps and walking distance
* Receive movement reminders
* View progress clearly
* Interact with friends
* Stay motivated through achievements and feedback
* My Role

### UX Researcher & UI Designer

I worked on problem framing, user journey mapping, user flow design, sketching, wireframing, UI design, and Figma prototyping.

## Research Process

I analyzed user needs around walking habits, reminders, motivation, and app retention. The project identified four major design needs:

1. Goal setting
2. Dashboard display
3. Reminder function
4. Friend interaction

I then mapped the user journey from discovering the app to setting goals, receiving reminders, joining challenges, and maintaining long-term engagement.

### Key Insights

Users need wellness tools that are easy to understand and naturally fit into their daily routines.

The research suggested that users may abandon reminder apps if notifications feel annoying. However, users are more likely to stay engaged when the app includes progress visualization, social interaction, challenges, and motivational feedback.

### Design Solution

The app was designed around a simple and supportive user flow.

#### Key design features included:

* Daily step goal setting
* Step and distance dashboard
* Reminder settings that users can adjust or disable
* Friend invitations and progress comparison
* Achievement and reward elements
* A green and blue visual system representing health, nature, and environmental awareness
* Final Outcome

The final prototype presents a wellness app experience that helps users track progress, manage reminders, and stay motivated through social features. The design emphasizes clarity, consistency, and low-effort engagement.

### Reflection

This project helped me think about behavior design and long-term user motivation. I learned that wellness apps need more than tracking features; they also need emotional support, flexible reminders, and meaningful feedback to encourage continued use.
